# DiagnoAssist Pro

A polished Arabic-first clinical workflow concept for psychologists, covering intake, differential diagnosis, assessments, results, analytics, and follow-up.

## Important

This repository is a product-design demonstration. It does not provide medical advice, a validated diagnostic model, real authentication, payment processing, or storage for identifiable patient information.

## Development

```bash
npm install
npm run build
```

The GitHub Pages workflow builds a static Next.js export automatically from `main`.
